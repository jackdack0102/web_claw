# Handmade Claw Shop

A minimalist, responsive storefront concept for handmade crochet items, keychains, and socks. Built with React, TypeScript, Vite, Framer Motion, and Lucide icons.

## Run locally

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. The current preview covers the storefront layout and visual direction; animated claw behavior and checkout flow are planned for the next steps.
